# Plugin Terms

The plugins in this repository are provided as local automation tools for operator-controlled workflows.

Users are responsible for complying with the terms of any websites, providers, or internal systems they access with these tools. The plugins do not grant permission to bypass access controls, scrape private data, or extract credentials.

TikTok monitor should collect only visible page content available to the configured browser session. CoBrowser and TikTok monitor must not be modified to read browser cookies, passwords, localStorage, sessionStorage, or token stores.
